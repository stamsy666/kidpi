# kidpi 0.3.4

## zapret: перебои
- kidpi включает в Windows TCP timestamps (`netsh interface tcp set global timestamps=enabled`) перед запуском winws.
  Файлы `general*.bat` от Flowseal делают это через `service.bat status_zapret`, а kidpi запускает `winws.exe`
  напрямую и пропускал этот шаг. Без timestamps 12 из 22 стратегий (все с `--dpi-desync-fooling=ts`)
  иногда ломают соединение. После обновления стоит заново подобрать стратегию.
- После выхода компьютера из сна kidpi перезапускает winws и tg-ws-proxy.

## Ускорение Telegram (tg-ws-proxy)
- Код прокси обновлён до текущего main Flowseal. Там исправлены ошибки
  `_call_connection_lost ... WinError 10054` и сокеты, которые после них оставались открытыми.
- Новый модуль `src-tauri/resources/tgws/kidpi/kidpi_tweaks.py`, загружается до прокси:
  - CF-домены перебираются параллельно (каждые 1,5 с добавляется ещё один, до трёх одновременно,
    на всё 12 с). Раньше каждый мёртвый домен ждали по 10 с, и Telegram успевал закрыть соединение.
  - Домены, которые недавно не ответили, ставятся в конец очереди, и для WS, и для H2.
  - Пауза между попытками прямого WS-пула теперь не больше 5 минут, раньше доходила до часа.
  - Модуль лежит отдельно от кода прокси и переживает автообновление tg-ws-proxy. В `tgws.log` появляется строка
    `kidpi tweaks: cf-domain-health, h2-domain-health, cf-race, ws-pool-backoff`.
