# kidpi — инструкция

## 1. Установка

1. Распакуй `kidpi-0.3.2-setup.zip` и запусти `kidpi_0.3.2_x64-setup.exe`. Файлы `.sig` и `latest.json` из архива нужны только для релиза на GitHub (раздел 3), для установки они не нужны.
2. Если Windows покажет «Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае». У установщика нет цифровой подписи, поэтому так.
3. Разреши запуск от администратора: без этих прав драйвер WinDivert, через который работает обход, не загрузится.
4. Ставить можно поверх старой версии. Если установщик спросит про удаление старой, можно согласиться: настройки и списки сайтов сохранятся.

Если антивирус удаляет WinDivert, kidpi напишет об этом на главном экране. Тогда добавь в исключения антивируса папки `C:\Program Files\kidpi` и `C:\ProgramData\kidpi` и переустанови kidpi.

## 2. Где что лежит

| Что | Где |
|---|---|
| Программа | `C:\Program Files\kidpi` |
| zapret, настройки, обновления | `C:\ProgramData\kidpi` |
| Журнал kidpi | `C:\ProgramData\kidpi\logs\kidpi.log` |
| Вывод winws (zapret) | `C:\ProgramData\kidpi\logs\winws.log` |
| Журнал tg-ws-proxy | `C:\ProgramData\kidpi\logs\tgws.log` |
| Настройки | `C:\ProgramData\kidpi\settings.json` |

Если что-то не работает, пришли текст из «Настройки → Журнал → Скопировать» и `winws.log`.

## 3. Автообновление kidpi через GitHub

kidpi проверяет GitHub через 30 секунд после запуска и потом раз в 6 часов. Если kidpi свёрнут в трей, новая версия ставится сама и программа перезапускается. Если окно открыто, у шестерёнки появляется точка, а в настройках кнопка «Установить kidpi X.Y.Z».

Обновление ставится, только если оно подписано твоим ключом `kidpi-updater.key`. Ключ я прислал отдельным файлом.

> **Ключ никому не показывай и не клади в репозиторий.** Если его потерять, уже установленные kidpi перестанут получать обновления: новую версию придётся один раз поставить вручную.

### Как это работает

kidpi берёт обновления из последнего релиза репозитория **`stamsy666/kidpi`**: файл `https://github.com/stamsy666/kidpi/releases/latest/download/latest.json`. В релизе должны лежать три файла:

| Файл | Зачем |
|---|---|
| `kidpi_X.Y.Z_x64-setup.exe` | установщик новой версии |
| `kidpi_X.Y.Z_x64-setup.exe.sig` | подпись установщика ключом `kidpi-updater.key` |
| `latest.json` | номер версии, подпись и ссылка на установщик |

Репозиторий должен быть **публичным**, а релиз не должен быть черновиком (Draft) или пре-релизом.

zapret и tg-ws-proxy обновляются отдельно, напрямую из репозиториев Flowseal, и от твоего GitHub не зависят: kidpi проверяет их при запуске (через 30 секунд) и потом каждые 6 часов, если включено «Обновлять автоматически».

### Вариант А: я выкладываю всё сам (проще всего)

1. Открой https://claude.ai/connect-github и подключи свой GitHub-аккаунт `stamsy666`.
2. Там же установи приложение Claude на репозиторий `stamsy666/kidpi`.
3. Напиши мне «подключил»: я залью исходники и выложу релиз 0.3.2.

Секрет `TAURI_SIGNING_PRIVATE_KEY` (шаг 3 варианта Б) нужен только для автосборки через Actions. Его добавляешь ты, у меня нет доступа к настройкам репозитория.

### Вариант Б: выложить релиз руками через сайт

Все три файла для релиза лежат в архиве с установщиком `kidpi-0.3.2-setup.zip`.

1. **Если репозиторий пустой**, без коммита релиз не создать. Открой https://github.com/stamsy666/kidpi и нажми **creating a new file**. Имя файла `README.md`, текст любой, например `kidpi`. Нажми **Commit changes**.
2. Открой https://github.com/stamsy666/kidpi/releases/new.
3. **Choose a tag** → впиши `v0.3.2` → **Create new tag: v0.3.2 on publish**.
4. Заголовок: `kidpi 0.3.2`.
5. Распакуй `kidpi-0.3.2-setup.zip` и перетащи в поле **Attach binaries** все три файла: `.exe`, `.exe.sig` и `latest.json`. Ничего не переименовывай.
6. Галочку **Set as a pre-release** не ставь, **Set as the latest release** оставь. Нажми **Publish release**.

Проверка: ссылка https://github.com/stamsy666/kidpi/releases/latest/download/latest.json должна скачивать файл, где написано `"version": "0.3.2"`.

### Исходники в репозиторий (для автосборки)

1. Распакуй `kidpi-source-0.3.2.zip` и отправь код (нужен установленный Git):
   ```bash
   cd kidpi
   git init
   git add .
   git commit -m "kidpi 0.3.2"
   git branch -M main
   git remote add origin https://github.com/stamsy666/kidpi.git
   git pull origin main --allow-unrelated-histories
   git push -u origin main
   ```
   Команда `git pull` нужна, только если в репозитории уже есть README из варианта Б.
2. В репозитории открой **Settings → Secrets and variables → Actions → New repository secret** и создай секрет:
   - имя: `TAURI_SIGNING_PRIVATE_KEY`
   - значение: всё содержимое файла `kidpi-updater.key` (открой его Блокнотом и скопируй).

   У ключа нет пароля, поэтому `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` создавать не нужно.

### Каждый раз: выпустить новую версию через Actions

1. Подними номер версии, например `0.3.2` → `0.3.3`, **в трёх файлах**:
   - `package.json` — строка `"version"`
   - `src-tauri/tauri.conf.json` — строка `"version"`
   - `src-tauri/Cargo.toml` — строка `version` в разделе `[package]`
2. Отправь изменения и тег:
   ```bash
   git add .
   git commit -m "kidpi 0.3.3"
   git tag v0.3.3
   git push
   git push --tags
   ```
3. Открой вкладку **Actions** в репозитории. Сборка идёт минут 10–15. Когда она закончится, во вкладке **Releases** появится `kidpi v0.3.3` со всеми тремя файлами.
4. Все kidpi версии 0.3.1 и выше найдут обновление при следующей проверке. Чтобы проверить сразу, открой «Настройки → Обновления → Проверить обновления».

### Другое имя репозитория

Если репозиторий будет называться не `stamsy666/kidpi`, а, например, `stamsy666/kidpi-app`:

1. В исходниках замени `stamsy666/kidpi` на своё в двух местах:
   - `src-tauri/src/settings.rs`, строка `DEFAULT_UPDATE_REPO`
   - `src-tauri/tauri.conf.json`, ссылка в `plugins → updater → endpoints`
2. У kidpi, который уже стоит на компьютере, есть два варианта:
   - один раз поставить вручную новую версию из своего Releases;
   - или, не переустанавливая, открыть Блокнотом от администратора `C:\ProgramData\kidpi\settings.json`, поменять `"updateRepo": "stamsy666/kidpi"` на своё и перезапустить kidpi.

## 4. Сборка вручную

**На Windows.** Нужны Node.js 22, Rust и Python 3.12.

1. Подготовь Python для tg-ws-proxy: выполни в PowerShell шаг «Prepare tg-ws-proxy runtime» из `.github/workflows/release.yml`.
2. Собери:
   ```bash
   npm install
   npx tauri build
   ```

**На Linux** (так собран присланный установщик). Сборка кросс-компиляцией описана в `README.md`.

Чтобы собранный установщик умел обновляться, перед сборкой задай переменную окружения `TAURI_SIGNING_PRIVATE_KEY` = содержимое `kidpi-updater.key`.

## 5. Что внутри

- **zapret** от Flowseal — https://github.com/Flowseal/zapret-discord-youtube (MIT). kidpi запускает его `winws.exe` со стратегиями из `general*.bat` и обновляет его из релизов на GitHub.
- **tg-ws-proxy** от Flowseal — https://github.com/Flowseal/tg-ws-proxy (MIT). Это «Ускорение Telegram»: локальный MTProto-прокси, обновляется из релизов на GitHub.
- Иконки: AnimateIcons, Heroicons Animated (MIT). Звуки: набор SND01 «sine» с snd.dev — перед публикацией проверь условия его использования.
